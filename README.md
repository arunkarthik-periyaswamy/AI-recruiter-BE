# Project base

How to install locally and develop

0. We used python 3.10.12

1. import the requirements
```bash
$ pip install -r requirement.txt
```
2. run the file  called application.py with the following contents:
```python application.py
```

3. develop

4. commit regularly, commit often  (with comments)
5. pull request, and ask someone to review before merging into the target branch
